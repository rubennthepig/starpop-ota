# Starpop Arcade OTA
Unofficial personal customization of [Y2Linux](https://github.com/SchulzCode/Y2Linux) and [Y2Reborn](https://github.com/SchulzCode/Y2Reborn). Patches are based on the matching upstream baseline-275 tags. The public key is for the Starpop update channel. No private key or personal library is included. No release is qualified or published by this initial setup.
